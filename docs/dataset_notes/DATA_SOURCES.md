# Dataset Sources

## 1. Indian Railways Train Delay Dataset
File:
`ir_train.csv`

Purpose:
Historical train delay / ETA modeling.

Local path:
`data/raw/railway/ir_train.csv`

---

## 2. IMD 0.25° Daily Gridded Rainfall
File:
`RF25_ind2025_rfp25.nc`

Purpose:
Daily spatial rainfall features.

Local path:
`data/raw/rainfall/RF25_ind2025_rfp25.nc`

---

## 3. India Flood Inventory v3
File:
`India_Flood_Inventory_v3.csv`

Purpose:
Historical flood events and district-level flood exposure.

Local path:
`data/raw/floods/India_Flood_Inventory_v3.csv`

---

## 4. District Flood Severity Index
File:
`DFSI.csv`

Purpose:
District Flood Severity Index.

Local path:
`data/raw/floods/DFSI.csv`

---

## 5. Railway Geographic Reference
Source:
DataMeet Indian Railways dataset.

Purpose:
Train routes, stations and schedules.

---

## 6. India District Boundaries
File:
`india_districts.geojson`

Purpose:
Spatial intersection between railway routes and districts.

---

### Note

Raw datasets are intentionally excluded from GitHub.
Each contributor should obtain the source datasets locally before running the pipeline.
